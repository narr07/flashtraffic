# Installing FlashTraffic

FlashTraffic is distributed as a lightweight, native Windows desktop application.

:download-card

## System Requirements

| Requirement | Minimum | Recommended |
| :--- | :--- | :--- |
| **Operating System** | Windows 10 (64-bit) | Windows 11 (64-bit) |
| **Memory (RAM)** | 4 GB | 8 GB or higher |
| **Storage** | 150 MB free disk space | 500 MB free disk space |
| **Runtime** | Microsoft Edge WebView2 (Pre-installed on Win 10/11) | Microsoft Edge WebView2 |

---

## Windows SmartScreen Notice

Because FlashTraffic is newly published and not yet signed with an expensive Extended Validation (EV) certificate, Windows Defender SmartScreen may show an alert on first launch:

> **"Windows protected your PC"**
> *Microsoft Defender SmartScreen prevented an unrecognized app from starting.*

### How to Bypass Safely:
1. Click **"More info"** on the dialog.
2. Click **"Run anyway"**.

FlashTraffic is 100% open-source software built transparently on GitHub Actions. You can inspect the entire codebase and build logs at [github.com/narr07/flashtraffic](https://github.com/narr07/flashtraffic).

## Building from Source

If you prefer to compile FlashTraffic locally on your computer:

### Prerequisites:
- [Rust](https://www.rust-lang.org/) (1.80+)
- [Bun](https://bun.sh/) (1.2+)
- Visual Studio C++ Build Tools

### Build Steps:

```bash
# Clone the repository
git clone https://github.com/narr07/flashtraffic.git
cd flashtraffic

# Install frontend dependencies
bun install

# Run the development app
bun run tauri:dev

# Build the release installer
bun run desktop:build
```

The resulting `.exe` and `.msi` installers will be located in:
`src-tauri/target/release/bundle/nsis/` and `src-tauri/target/release/bundle/msi/`.
